# Stilreferenser för kategoribilder

Lägg 3–10 godkända referensbilder i den här mappen före driftsättning. Tillåtna format är `.jpg`, `.jpeg`, `.png` och `.webp`.

Bilderna skickas som stilreferenser till Gemini Nano Banana 2 när en kategoribild skapas. Använd bilder med den önskade, konsekventa RebuildR-stilen. De får inte innehålla text, logotyper, vattenstämplar eller känsligt material.

Filerna versioneras i projektet och kopieras till `dist` av Nest-bygget.
